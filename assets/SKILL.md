# 真人语感文案

唯一判断标准：**这句话，这个人此刻真的会这么开口吗？**

不像人说话，通常不是词不够美，是三件事错了——说话人不是一个具体的人、句子太长、没有一个可核对的实物。按下面五步走。

## 零号规则：不写任何能被读成病症的语言

这条压过其余所有规则。判据只有一句：**读者能不能从这句话里推出「这个人身体有病 / 某个指标不正常 / 正在接受某种治疗」？** 能，就重写。

| 禁写 | 例子 | 换成 |
|---|---|---|
| 病名、症状名 | 高血压、失眠、便秘、胃炎、上火、湿气、炎症、三高、免疫差 | 生活行为：`饭后坐着不动`、`作息乱`、`口味重` |
| 指标与检查 | 体检单、指标、化验、画了圈、超标、复查、报告单 | 时间与习惯：`去年开始注意吃饭`、`这半年` |
| 药名与治疗动作 | 华法林、降压药、他汀、疗程、见效、缓解、根治、吃三天就好 | 只留通用提示：`正在吃药的先问医生` |
| 身体机能描述 | 上楼喘、夜里起夜三次、眼睛干、腰疼、睡不着、胀气、掉头发 | 行为画面：`上楼比以前慢`、`愿意下楼走一圈`、`饭后出去转二十分钟` |
| 因果与功效归因 | 吃了它血压降了、不再失眠、三天见效 | `我不敢说是它管用`、`这半年他作息倒是规律了` |

**允许写**：年龄、地点、次数、价格、时间、三餐、作息、穿戴、家务、走路、聊天、口味、包装、批号原文、禁忌人群（孕产妇、小孩、正在吃药的）。

### 感受可以写，但不许给它命名

这是零号规则里最常被问的一条。**诱因、动作、行为改变全能写，只有"给感受起个名字"不行。**

- **可写诱因**：阴天、下雨、降温、换季、早起、站久了、坐久了、搬完东西、爬完楼
- **可写动作**：捶腿、扶扶手、坐下缓一会儿、把腿架起来、提前穿秋裤、少走两步、那两天不接活
- **不可写命名**：骨头疼、关节疼、风湿、骨刺、酸麻胀痛、发炎
- **万能句式**：「一变天，我就 X」——只写 X 这个动作，不写为什么

| 三档 | 词 | 用法 |
|---|---|---|
| 白 | 使不上劲、不利索、沉、紧 | 可用，但必须配一个动作，不单独成句 |
| 灰 | 酸、木、僵 | 一条最多一次，且不接任何病名 |
| 黑 | 疼、痛、肿、麻、炎、骨刺、风湿、关节炎 | 一次都不出现 |

对照：

- ❌ 一到阴天下雨，我骨头疼得厉害，脸都皱起来
- ✅ 一到阴天下雨，我下楼得扶扶手，那两天不接活
- ❌ 膝盖疼，蹲下去起不来
- ✅ 蹲下去得扶一下地，起得比以前慢

**唯一例外**：合同、条款、审批文本、包装标签的原文照抄——那是法律文本，不是描述说话人身体。照抄时加引号，并说明是照抄。

### 连画面一起禁：场景、形象、背书

语言干净不算完，镜头里出现这些照样被驳回。

| 类别 | 禁 | 换成 |
|---|---|---|
| 场景 | 药店、药店货架、医院走廊、诊室、化验单特写 | 家里餐桌、工位、超市货架、快递箱 |
| 形象 | 白大褂、听诊器、护士帽、病历本 | 围裙、工装、居家服 |
| 背书 | 「体检医生说」「专家建议」「三甲医院推荐」 | 「我自己翻的成分表」「我妈的原话」 |
| 擦边画面 | 揉眼睛、揉膝盖、按太阳穴、捂肚子 | 把眼镜摘下来擦、把腿架起来、坐下缓一会儿 |
| 心理暗示 | 字幕写「焦虑」「抑郁」「心情好多了」 | 写行为：「这半年他愿意下楼了」 |

判据：镜头里只要有「白大褂 + 药 + 诊室」任意两样，整条按医疗场景处理。

## 平台过审清单（发布前逐条过，一条不过就重写）

1. **极限词**：最、第一、唯一、顶级、性价比最高、近两年最划算、直接拉满——一个都不留
2. **诱导点击**：「点击下方」「点击」「左下角」「小黄车」「戳链接」——全禁；要引导就写「东西在这条下面」
3. **医疗词**：血糖、控糖、消化不好、视力下降、药、药片、苦药片、战胜坏菌、肚子舒服——出现即删
4. **效果承诺**：「饭后来一条，肚子舒服」「三天就有感觉」——删，改成当天怎么吃
5. **时效性**：过期活动（国庆、金秋、上个月的活动）一律不提；写「限时」「最后一天」必须当天真是这样
6. **拉踩**：不拿自家 A 产品贬自家 B 产品，也不点名别家
7. **梗与反讽**：下沉中老年受众不吃这套，一条稿零个梗
8. **标题必须对应正文**：标题写叶黄素，正文就不能讲骨胶原——错配本身构成医疗暗示
9. **术语落地**：「服用」写「吃」，「功效」写「管啥用」，「适用人群」写「谁别吃」
10. **产品信息只说一遍**：成分、机制、价格各出现一次，不重复播报

## 蓝帽分叉：有没有批号，写法完全不同

动笔前先问一句：**这个产品有蓝帽（保健食品批准文号）吗？** 不确定就按「没有」写。

| | 有蓝帽 | 没有（普通食品 / 未批功能） |
|---|---|---|
| 功能名 | 可照抄一项批准原文，一词不改，并说明是照抄 | **一个字都不能出现**（补充 B 族维生素、改善睡眠这类也不行） |
| 能写的 | 批准功能 + 成分 + 吃法 + 场景 + 别人反应 | 成分、含量、吃法、口感、包装、场景、别人反应 |
| 感受的尺度 | 可带一句泛化感受（感觉挺好），一条最多一处 | 同上，且不接任何部位 |

判据：无蓝帽时，凡是「吃了它身体会怎样」的句子，一律删掉；只留「怎么吃、多少钱、谁在吃、别人怎么看」。

## 零号规则的出口：功效侧写（不许直说，就让人替你说）

功效词一个都不能出现：养颜、抗衰、美白、补气、调理、排毒、增强体质、改善体质。**但可以让别人对她的反应把话说了。**

三条硬规则：

1. **只呈现误会，不解释误会**。让配角看错、认错、猜错，说得越平常越好。
2. **主角不认账**。被夸要说「没有」「你闭嘴」「瞎说啥」，绝不顺着接。
3. **最后一镜也不解释**。不写「因为吃了它」。收尾用三句之一：`别的不说。` / `我也没觉得累。` / `这个我不懂。`

**不认账 ≠ 否认。这是最容易写废的一条。**

| 写法 | 例子 | 结果 |
|---|---|---|
| ✅ 不认账 | 「人家眼神好」「我自己买的，没花你钱」「你管得着吗」「喝得起呗」 | 效果摆在那，她只是不承认是自己的功劳 |
| ❌ 否认 | 「不知道」「没感觉」「别指望」「跟你说实话没用」 | 把产品说死，观众转身就走 |

判据一句话：整条稿读下来，观众的感觉应该是**「这人一直在用」**，不是**「这东西没用」**。

被问「管用吗」的三句标准答法：
- `你问这干啥。`（挡回去）
- `喝着呗，我又没让你买。`（不接，反劝退）
- `我自己买的。`（用花钱这个动作代替回答）

| 侧写素材 | 怎么落到台词里 |
|---|---|
| 陌生人误判 | 公交没人让座、地铁查卡问「这卡你的？」、领队以为是刚退休的、快递叫「姐」不叫「阿姨」、摊主抹零、理发师问要不要染 |
| 熟人反应 | 同事以为是我姐、老姐妹问是不是换了护肤品、邻居打量两眼 |
| 服务差别 | 老板多送一把葱、店员主动递凳子 |
| 自己的行为 | 愿意站着、多走一站、以前找座现在不找 |

**灰度**：可以说「看着不像」「没认出来」，不能说「年轻十岁」「像四十」。

> **公交版（35s）**
> （公交车。妈站在门边，儿子扶着杆）
> 儿子：妈，你坐啊。
> 妈：两站地。
> 儿子：不是——人家咋不给你让座了？
> 妈：我站着呢。
> 儿子：我说以前。
> 妈：以前我一上车就找座。
> 儿子：现在呢？
> 妈：现在想站会儿。
> 儿子：……行吧。那你累不累啊？
> 妈：不累。
> 儿子：得，你赢了。
> （字幕：早上两粒，吃了八个月。成分表在评论区）

> **菜场版（30s）**
> （菜市场。摊主称完菜）
> 摊主：大姐，抹个零。
> 妈：为啥？
> 摊主：看着顺眼呗。
> 儿子（在旁边）：我妈天天早上吃那个。
> 妈：你闭嘴。
> （字幕：瓶子在电视柜上，她自己记得吃）
> 儿子：我说的是实话啊。
> 妈：走了。

## 卖货短视频的八个节拍（中老年、45–60s）

嘴上不能停。纯画面加零台词是文艺片，不是卖货。

| 节拍 | 写什么 | 例子 |
|---|---|---|
| 1 身份 | 年龄 + 一句身份 | 我今年六十二 |
| 2 动作 | 一个具体动作，不解释 | 拎两袋菜，一口气上五楼 |
| 3 旁人反应 | 有人喊她慢点、邻居看一眼 | 闺女在后头喊：妈你慢点 |
| 4 去年同动作 | 同一件事的旧版本，字幕标「去年」 | 上到二楼得把菜放下，坐台阶歇一会儿 |
| 5 转折问句 | 自问自答，把话头转向产品 | 我吃的是啥？ |
| 6 产品落到数字 | 品类 + 规格 + 吃法 | 胶原蛋白肽，一条五克，温水一冲 |
| 7 算账 + 反向劝退 | 一天多少钱；先别囤 | 一天三块多；先买一盒，没用别续 |
| 8 动作 | 一个去处，不写「点击」 | 评论区扣个「胶原」 |

前四拍必须在 12 秒内说完，第 5 拍之前一个字不提产品。

### 三样对照（让产品显得有用）

1. **同动作前后**：去年坐台阶歇，现在一步不停
2. **字幕标时间**：左下角「去年 / 现在」，不靠嘴说
3. **别人点破**：邻居一句「今年没见你坐台阶了」——产品自己永远不下结论

### 卖货稿的语音要求

- 每 5 秒必须有人说话，静默超过 5 秒就是文艺片
- 一句一换气，单句不超过 14 字
- 每 3 句出现一个数字或具体物（五楼、两袋、三十条、三块多）
- 结尾必有一个动作指令，且不是「点击」类词
- **反向劝退**至少一句：「先别买三盒」「没用别续」——这一句最能换信任

## 信息流投放：35 秒结构（和内容号不是一套）

内容号先立人再出产品；信息流前 3 秒决定划走，**产品必须在 8–15 秒出现**。

| 时间 | 干什么 | 写法 |
|---|---|---|
| 0–3s | 动作 + 一句冲突喊话 | 她拎两袋菜上楼，画外「妈你慢点！」，她「不用慢。」 |
| 3–8s | 去年同一个动作（对照） | 去年上到二楼得坐台阶歇，今年没坐 |
| 8–15s | 产品落地：品类 + 规格 + 吃法 | 我今年六十二，吃的是这个，胶原蛋白肽，一条五克 |
| 15–22s | 算账 | 一盒三十条，一天一条，一天三块多 |
| 22–30s | **反向劝退** | 三十条吃完你自己说，没用别续 |
| 30–35s | 一个去处 | 想看成成分的，我主页上有 |

硬要求：
- 总长 30–35 秒，超过 40 秒完播掉崖
- 前 3 秒不能是静止人脸，必须有动作和声音
- 字幕逐句上大字，关键词（六十二、五克、三十条、三块多）放大
- 现场音（塑料袋、钥匙、脚步、水声）至少占一半，别全场配音
- 竖屏 9:16，人物居中偏下，上方留 20% 给字幕

### 量产：产品段一个字不动，只换三处

| 变量 | 取值池 |
|---|---|
| 动作 | 拎菜上楼、扛面、抱孙子起身、蹲下系鞋带、跨下公交、踮脚够柜顶、双手拎水桶、端一摞碗 |
| 对照物 | 台阶坐下歇、拉小车、扶栏杆、换手、扶墙缓一下 |
| 点破的人 | 闺女、儿媳、邻居、摊主、老伴、广场舞领队、孙子 |

一个骨架出六条，够测两周。**数字段（品类/规格/单价）是转化核心，不要动它。**

### 各品类禁写（功能名分叉）

| 品类 | 能写 | 不能写（除非有蓝帽批准原文） |
|---|---|---|
| 钙 | 液体钙、一天一支、三十支 | 补钙、增加骨密度 |
| 氨糖 | 氨糖、一天两粒、六十粒 | 关节、软骨、膝盖 |
| 叶黄素 | 叶黄素、一天一粒 | 护眼、视力、眼干 |
| 蛋白粉 | 蛋白粉、一天一勺 | 增肌、免疫力 |
| 鱼油 | 鱼油、一天两粒 | 降血脂、清血管 |
| 骨胶原 | 胶原蛋白肽、一条五克 | 抗衰、紧致、关节 |

### 价格必须是能对上的三个数

单价 × 天数 = 一盒钱。改任何一个，另外两个同步改。对不上等于编造。

## 第一步：语域五问（答不出就填 `[PLACEHOLDER]`，不要跳过）

| 项 | 要具体到 | 反例 |
|---|---|---|
| 谁在说 | 年龄、职业、身份、和产品的关系 | 「品牌方」 |
| 对谁说 | 一个人，或一小群有共同处境的人 | 「广大用户」 |
| 什么关系 | 熟人 / 陌生人 / 上下级 / 老客户 / 家人 | 「目标客群」 |
| 此刻什么场合 | 他在干什么、为什么现在要说这句 | 「营销场景」 |
| 说完要他干什么 | 一个动作、一个去处 | 「提升转化」 |

五问里「场合」最容易被跳过，也是真人语感的第一来源：在地铁上、在厨房、刚被客户骂完、抱着孩子——同一句话会写成三个样子。

## 第二步：选基调（先定，再写）

| 基调 | 句式特征 | 用在 | 开头长什么样 |
|---|---|---|---|
| **A 喊话体** | 问句连发、数字前置、第二人称「你」、短句砸下来 | 信息流投放、工厂直播、口播带货 | 「到底饭前吃还是饭后吃？早上还是晚上？」 |
| **B 聊天体** | 一句一行、第一人称「我」、有细节有让步 | 视频号、小红书、朋友圈、私域 | 「我妈今年六十三。」 |
| **C 说明体** | 结论先行、一句一个事实、不抒情 | 详情页、FAQ、客服、公告 | 「这个不便宜，一盒 168。」

一条稿只用一种基调，不要混。混了就变成「同事在念 PPT」。

## 第三步：真人句的 10 个可测量特征

写的时候逐条对，缺三条以上就重写。

1. **句长**：6–14 字为主，每 5 句允许一个 2–4 字的短句砸下来。不出现 30 字以上的复合句。
2. **具体物密度**：每 2 句出现一个可核对的东西——数字、时间、价格、地名、品牌、型号、粒数、楼层层数。「今天早上」「两粒」「168 块」「三楼」都算。
3. **动词优先**：形容词最多连用两个。「优质高效」写成「早上八点前能发出去」。
4. **口语连接词**：就、倒是、其实、反正、结果、后来、说白了、你看、你说、对吧、呗、呢。一段里至少两个，不要五个。
5. **对手信息 / 无关细节**：真人会带出不服务于卖点的细节——「钙片我买过三种，她全搁抽屉里」。这是真实感最便宜的做法，一句就够。
6. **主动降期待**：每条至少一句「我不敢保证」「这个不一定适合你」「我一开始也不信」。
7. **照抄原文，不转述**：法规文本、批号、参数、客户原话，直接引号贴上去：「盒子上批的就四个字，改善睡眠」。
8. **预判反驳**：「你别看它包装简单，就以为成分不行」——把对方心里那句话先说掉。
9. **一个立场**：不给「各有各的好」。要夸就夸一个点，要骂就骂一句，剩下的不评价。
10. **结尾落在动作或细节**：不升华、不总结、不「让我们一起」。最后一句要么是一个指令，要么是一个画面。

## 第四步：AI 腔病灶 → 处方

| 症状 | 长这样 | 改法 |
|---|---|---|
| 三段排比 | 「省时、省力、省心」 | 留一条，另两条写成具体场景 |
| 抽象名词 | 赋能 / 闭环 / 抓手 / 生态 / 一体化 / 焕新 / 打造 | 换成「谁对谁做了什么」 |
| 空形容词 | 优质、专业、极致、贴心、匠心 | 换成一个能验证的事实或数字 |
| 大厂连接词 | 因此、从而、此外、然而、值得注意的是、综上 | 全删。用「所以」「还有」「不过」 |
| 总结升华段 | 「这就是我们坚持的意义」 | 整段删。删完如果更顺，说明它本来就不该在 |
| 对称结构 | 首先…其次…最后 | 打散成「我最想说的是…另外还有件事」 |
| 全都要 | 「既…又…还…」 | 只留一个，其余承认做不到 |
| 客服腔 | 「亲爱的用户，感谢您的支持」 | 「你这个情况我遇到过，先说结论」 |
| emoji 堆砌 | 🎉✨🔥 每句一个 | 一条最多 1 个，或全删 |

## 第五步：改写原子动作（改现成文案时按顺序过一遍）

1. **圈**：圈出所有抽象名词和形容词，问「具体指什么」。答不上来就删。
2. **拆**：找最长那句，超过 20 字就断开。
3. **换**：把「我们公司／本产品／平台」换成「我／这个／它」。
4. **补**：给第一句补上时间、地点或一个动作。
5. **删**：删掉最后一段，大概率是升华。
6. **留**：加一句代价或不确定。
7. **收**：结尾换成一个具体指令或一个画面。
8. **念**：出声念一遍。拗口、要换气、读着像播音的地方，就是 AI 留下的痕迹，重写那一句。

## 第六步：过一遍嘴（口语化终检）

这一步不做润色，做**复述**：假装你正跟邻居说这件事，说完再记下来。写不出来，说明还没过嘴。

### 书面化的 8 个痕迹

| 痕迹 | 长这样 | 改成 |
|---|---|---|
| 完整主谓 | 我妈今年六十四岁 | 我妈六十四了 |
| 连词成串 | 但是、所以、而且、虽然 | 删，用停顿，或换成「可」「结果」 |
| 判断句 | 这是……的 | 换动作：她搁电视柜上放着 |
| 抽象转折 | 我不敢说是它管用 | 管不管用我哪知道 |
| 对称排比 | 穿暖点、少站会儿，都算 | 穿暖点呗，别老站着 |
| 书面称呼 | 母亲、长辈、老人 | 我妈、俺娘、老太太 |
| 解释因果 | 因为天冷，所以她就…… | 天一冷，她就…… |
| 一字一顿的短句 | 她。不。去。 | 她不听，劝了也不听 |

### 12 个口语动作

1. **语气词收尾**：细则见下面「语气词」一节。一句最多一个。
2. **追补**：说完再补半句。`她不去。劝了也不去。`
3. **半截句**：`我劝她少站会儿，她——算了。`
4. **重复**：`就那样，一直那样。`
5. **自我打断**：`我说你少站会儿……嗐，说了白说。`
6. **动作代替形容**：不写「难受」，写「脸皱一下」。
7. **称呼落到人**：我妈、俺娘、老太太、老周。
8. **数字口语**：六十四、两粒、一年半、三楼。
9. **插一句不懂**：`这个我不懂。` `我不掺和。`
10. **转述别人的话**：`她说：不用管，管它干啥。`（转述可以，别自己下诊断）
11. **反问收尾**：`你说是不是这个理儿。`
12. **一口气念得完**；念不完就断句。

### 语气词（最容易漏的一层）

没有语气词的是「念出来的稿子」，有语气词的才是「说出来的话」。

**库**：啊 呀 呗 嘛 嘞 喽 啦 哈 呐 哦 咯 诶 咦 哎 哎呀 哎哟 嚯 嗐 嗯 唉

**三个位置**
1. 句末：`就这个呗。`
2. 句中停顿：`天一阴哪，下楼就得扶栏杆。`
3. 句首感叹：`哎，我妈六十四啦。` / `嚯，这风刮的。`

**变音要写出来**（真人感的关键细节）：
- 前字收 n / ng：啊 → 哪（`天一阴哪`、`你看哪`）
- 前字收 u / ao：啊 → 哇（`哪知道哇`、`好哇`）
- 其余：啊 → 呀（`你去呀`）

**密度（宁少勿多）**
- 一条 12 行的稿，**4–6 个**就够，平均每 2–3 句一个
- 连续两句都带 = 删掉一个
- 一段（4 行）最多 2 个
- 机制句（价格、粒数、截止日、成分名）**0 个**
- 写完把语气词全圈出来数一遍，超过 7 个就往下删；删到 5 个附近再念，顺就停手

**按人分配**
- 六十上下长辈：啊、呀、呗、嘞、喽、啦
- 三十上下：哈、哦、咯、诶、嘛
- 播音腔信号：吗、呢、吧 用得整整齐齐（「你不去吗」「就是这样呢」）

**别把语气词堆在卖点上**：生活句随便带，机制句（价格、粒数、截止日）保持干净，念出来才有劲。

> 没语气词：我妈六十四岁。天一阴，她下楼要扶扶手。
>
> 有语气词：我妈六十四啦。天一阴哪，下楼就得扶栏杆。

### 方言

详见 `references/dialects.md`（东北、川渝、江浙沪、粤、山东、河南、西北，各带替换词表与例稿）。

- 一条稿 **3–6 个**方言词，超过就是演自己。
- **一地区用到底，不串**。东北混川渝，立刻假。
- 不懂就不写。只在语气词上做口语化，也比硬套方言强。
- 字幕用字统一，别一半普通话一半方言。

对照（同一件事）：

> 书面：我妈今年六十四岁，一到阴雨天，她下楼就需要扶扶手，广场舞也不参加了。
>
> 口语：我妈六十四了。天一阴，下楼就得扶栏杆，广场舞也不去了，搁楼下坐着看人家跳。

## 体裁规格

| 体裁 | 字数/行数 | 硬要求 |
|---|---|---|
| 短视频口播 15s / 30s / 45s / 60s | 65 / 140 / 200 / 285 字（4.5 字/秒，±20） | 第一句必须是具体画面或具体问句 |
| 字幕短句版 | 8–14 行 | 不加标点，一行一个信息点，硬切 |
| 朋友圈 | 3–6 行，60–120 字 | 第一行就要有信息，不写「记录一下」式开头 |
| 小红书 | 150–400 字，分 4–6 段 | 敢写缺点，敢写价格，不比价不拉踩 |
| 公众号开头 | 100–200 字 | 从一个人、一件事、一个数字进场，不从时代背景进场 |
| 产品详情页 | 分块，每块 ≤40 字 | 一块一个事实，标题是结论不是名词 |
| 私信 / 客服 | 30–80 字 | 先答问题，再给下一步，不寒暄 |
| 广告语 / 海报 | ≤14 字，可加一行副标 | 有主语或动词，不做名词堆叠 |
| 短信 / 推送 | ≤35 字（含称呼） | 第一屏要能读完，带一个动作 |
| 招聘 JD | 200–400 字 | 说清加不加班、几个人、向谁汇报，不说「自驱」 |
| 自我介绍 / 个人简介 | 60–150 字 | 一个身份 + 一个数字 + 一句在做什么 |

## 交付格式

默认给两版，一版一基调，标注适用场景：

```
【A｜喊话体】—— 投流 / 直播 / 口播
（正文）

【B｜聊天体】—— 视频号 / 小红书 / 私域
（正文）

一句标题：xxx（可选，能当海报或推送首句）
```

用户指定了体裁和基调就只给一版。只给正文，不写「以下是为您创作的」，不解释思路，不附写作说明。

### 用于生视频时，交五件

文案要送进文生视频 / TTS / 剪映 / 字幕识别时，五份一起给，缺一份剪辑就得回头问。

1. **人物卡**——年龄、身高体型、发型、服装（颜色+材质）、面部细节、气质、说话方式。写到能直接生图的程度。
2. **分镜表**——镜号 | 秒数 | 景别/机位 | 画面与动作 | 台词。一镜一事，不写「她很难过」这种结论，只写看得见的东西。
3. **配音稿**——纯文本，一行一句，无标记，直接粘 TTS。
4. **标注稿**——同一份文本，口语字用 `[字]` 圈出，带镜号与画面，供对稿和字幕校对。
5. **字幕**——单独列，不混进配音稿（混进去机器会念出来）。

只标四类口语字：**语气词、变音字、儿化、方言字**。普通汉字不标。

**关键一条：变音字在配音稿里写本字。** 写「哪」TTS 会读 nǎ（哪里），得写「啊」它才读轻声 a；字幕再按实际发音写「哪」。

| 原句 | 配音稿 | 标注稿 | 字幕 |
|---|---|---|---|
| 天一阴哪 | 天一阴啊 | 天一阴[啊/na] | 天一阴哪 |
| 哪知道哇 | 哪知道啊 | 哪知道[啊/wa] | 哪知道哇 |
| 六十四啦 | 六十四啦 | 六十四[啦] | 六十四啦 |
| 我不去喽 | 我不去了 | 我不去[喽] | 我不去喽 |

**TTS 友好六条**
1. 数字写汉字：`2 粒` → `两粒`，`168 元` → `一百六十八元`
2. 破折号、省略号全删，换逗号或句号（TTS 会把「——」读成停顿或吞掉）
3. 一行一句，句与句之间空行
4. 括号里的画面提示**不进配音稿**，只留在标注稿
5. 方言字按目标地区判断：非该地区配音，TTS 会读成普通话谐音，宁可换词
6. 吞音严重的「喽、嘞、呗」，配音稿可退回「了、的、吧」，字幕保留原字

## 正反对照（照这个语感写）

**① 口播 45s｜卖磷虾油｜反例（模型腔）**
> 在当今快节奏的生活中，越来越多的人开始关注营养补充。今天为大家带来一款高品质的磷虾油产品，它富含多种营养成分，能够全方位满足您的日常需求，为您的健康保驾护航。

**① 正例（A 喊话体）**
> 磷虾油到底饭前吃还是饭后吃？早上吃还是晚上吃？
> 今天一条视频讲明白。
> 我手上这批，是我自己去工厂谈的。
> 拍一盒发两盒，到手整整 120 粒。
> 一粒里 DHA、EPA、虾青素、胆碱、磷脂，五样都在。
> 你别看它包装简单，就以为成分不行。
> 每天早饭后来两粒。
> 这个机制就到这个月底，下次没有这个价。

**② 口播 45s｜子女买给爸妈｜增加骨密度｜正例（B 聊天体）**
> 我妈今年六十三。
> 以前她吃完饭就坐沙发上，遥控器搁腿上。
> 我没敢乱买。先看盒背面的蓝帽子，批的什么就写什么——增加骨密度。

> 我不敢说是它管用。人上了年纪，愿意动一动就是好事。
> 想要成分表的，评论区我置顶了。

**③ 朋友圈｜宠物店｜反例**
> 🐾 感恩回馈！本店推出超值洗护套餐，专业团队用心呵护，让您的爱宠焕然一新，快来体验吧！✨

**③ 正例**
> 今天给一只十六岁的猫洗澡。
> 它主人说，这可能是它最后一次来了。
> 我洗完多梳了十分钟，没收钱。
> 老年猫洗护这个月八折，直接来就行。
