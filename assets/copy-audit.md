# 文案红线审核

审的是**字面**，不是文笔。一条稿进来，输出三样：逐句判定表、总评、可发布/不可发布。

**分工**：本技能查「有没有越过红线」；`human-voice-copy` 查「骨架有没有换」。别混。

## 输入（缺项按最严假设）

- 文案正文（整篇或逐句）
- 产品是否**有蓝帽**（保健食品批准文号）：有 / 无 / 不确定
- 品类：保健食品 / 普通食品 / 化妆品 / 器械 / 服务

蓝帽不确定时，按**无蓝帽**审——这是唯一安全的默认。

## 判定四档

| 档 | 含义 | 处理 |
|---|---|---|
| 🔴 红线 | 字面已经构成功效宣称、疾病治疗、虚假背书 | 必删或必改，改完才能发 |
| 🟡 灰区 | 边界模糊、靠暗示站住 | 限量（一条最多一处）或改写成行为画面 |
| 🟢 安全 | 事实、场景、成分、价格、吃法 | 保留 |
| ⚫ 编造 | 机制、数据、资质、报告无依据 | 补依据或删 |

## 十二条检查线

1. **病名与症状**：高血压、失眠、便秘、胃炎、上火、湿气、炎症、三高、免疫差
2. **身体机能描述**：上楼喘、起夜三次、眼睛干、腰疼、睡不着、胀气、掉头发
3. **指标与检查**：体检单、指标、化验、超标、复查、报告单
4. **药名与治疗动作**：华法林、降压药、他汀、疗程、见效、缓解、根治、吃三天就好
5. **功效词**：养颜、抗衰、美白、补气、调理、排毒、增强体质、改善体质
6. **功效归因**：「吃了它，血压降了」「不再失眠」——把结果钉在产品上
7. **时间承诺**：三天见效、一个月根治、七天瘦十斤
8. **绝对化**：最、第一、唯一、100%、彻底、永久
9. **保证性用语**：保证、包好、无副作用、绝对安全
10. **无蓝帽却引功能名**：普通食品说「补充 B 族维生素」「改善睡眠」——功能名只有蓝帽批过才能照抄
11. **虚假背书**：专家推荐、三甲医院、临床试验、患者见证、销量第一（无出处）
12. **人群越界**：对孕产妇、婴幼儿、慢病人群做推荐，或暗示可替代药物
13. **医疗场景与形象**：药店、药店货架、医院走廊、诊室、化验单；白大褂、听诊器、护士帽、病历本。有「白大褂 + 药 + 诊室」任意两样即判 🔴
14. **医疗背书**：「体检医生说」「专家建议」「三甲医院推荐」「临床验证」——无出处一律 🔴
15. **擦边画面**：揉眼睛、揉膝盖、按太阳穴、捂肚子、疲劳特写；字幕写「焦虑」「抑郁」「心情好了」——🟡 起步，配产品名即 🔴
16. **极限词**：最、第一、唯一、顶级、性价比最高、近两年最划算、直接拉满——🔴
17. **诱导点击**：点击下方、点击、左下角、小黄车、戳链接——🔴
18. **标题与正文错配**：标题写叶黄素、正文讲骨胶原，这类错配按医疗暗示判 🔴
19. **时效性**：过期活动（国庆、金秋、上月促销）、无依据的「限时/最后一天」——🔴
20. **拉踩与内部对比**：拿自家 A 产品贬自家 B 产品，或点名别家——🔴
21. **梗与反讽**：反讽、玩梗、网络黑话面向中老年下沉受众——🟡 建议删
22. **术语不落地**：「服用」「功效」「适用人群」——🟡 改成「吃」「管啥用」「谁别吃」
23. **价格勾稽不上**：单价 × 天数 ≠ 一盒钱——⚫ 编造，三个数必须能对上
24. **品类功能名越界**：钙写「补钙」、叶黄素写「护眼」、鱼油写「降血脂」、蛋白粉写「增肌」——无蓝帽即 🔴，有批文只能照抄批准原文
25. **信息流时长与产品时点**：超过 40 秒、或产品在 15 秒后仍不出现——🟡 完播与转化双损
26. **功效三处缺位**：开头没有「结果」、中段没有「去年同一件事」、结尾没有「旁人主动」——🟡 少一处转化就弱一档，三处全无等于没卖点
27. **对话全在办事**：没有废话、没有答非所问、结尾硬转——🟡 观众会觉得假

## 画面也要审

判定表除句子外，加一行「画面/场景」，因为平台是按成片审的：

```
【画面判定】
- 场景：药店/医院/诊室 → 🔴
- 形象：白大褂/听诊器 → 🔴
- 动作：揉眼/揉膝/捂肚子 → 🟡（配产品名 → 🔴）
- 字幕：心理状态词 → 🟡
```

## 同质化检测（比十版更狠的一条）

除了「十版重复检测」，再查三件事：

| 症状 | 判据 |
|---|---|
| 扒老视频 | 与历史脚本逐句比对，改动词不改结构 |
| 多视频一致 | 同一批 5 条素材，开头句式完全相同 |
| 形式单一 | 全部是单人口播，零对白、零场景 |

改法只有一条：**换骨架**（开场类型 / 叙事人称 / 转折诱因），不是换词。

## 输出格式

```
【判定表】
1 | 原句原文 | 🔴/🟡/🟢/⚫ | 触犯第几条 | 一句话改法
2 | ...

【总评】
红线 N 处，灰区 N 处，编造 N 处
结论：可发布 / 改完再发 / 不可发布

【最该先改的三句】
1. 原句 → 改法（为什么）
```

改法只给**单句替换**，不给整篇重写。用户要整篇重写时，转 `human-voice-copy`。

## 安全区的边界（判定时用）

**可以留**：
- 泛化感受：「感觉挺好」「整个人清爽点」「舒服些」——一条最多一处，且不接具体部位
- 生活行为：饭后坐着不动、外卖点得多、青菜见不着、愿意下楼走一圈
- 成分与含量：B1、B2、DHA 1000mg、每片 500mg
- 吃法与价格：早饭后两片、一盒 168、一瓶 60 片
- 禁忌提示：孕产妇、小孩、正在吃药的先问医生

**必须走**：
- 任何「部位 + 感受」组合：腿不疼了、腰不酸了、眼睛不干了
- 任何「指标 + 变化」组合：血脂降了、血糖稳了
- 任何「药 + 替代」暗示：不用吃药了、可以停了

## 十版重复检测（结构层）

同一 brief 连出十版，按四维打分：

| 维度 | 怎么判 | 危险信号 |
|---|---|---|
| 开头句式 | 十版第一句是不是同一句型 | 全是「我以前……」 |
| 叙事顺序 | 场景→产品→机制→CTA 是否固定 | 十版顺序一模一样 |
| 转折位置 | 「后来」「结果」出现在同一段位 | 全部第 4 行转折 |
| 收尾动作 | CTA 是否同一种 | 全是「评论区置顶」 |

**假变化**：只把「同事给我的」换成「我妈给我买的」，其余不动——说话人换了，骨架没换。这不算换。

输出：

```
重复度：开头 X/10 同型，顺序 X/10 相同，转折 X/10 同位，收尾 X/10 同式
真变化：N 版
骨架替换建议：换开场类型（问句/对白/动作/数字）、换叙事人称（我/他/旁观）、换转折诱因（他人误判/自身体验/服务差别）
```

## 两条判例

**例一（🔴 三处）**
> 我妈膝盖疼，吃了这个三个月，现在爬楼不喘了，专家都说好。

- 第 1 句 🔴 第 2 条（机能）+ 第 1 条（症状）：膝盖疼
- 第 2 句 🔴 第 6 条（功效归因）+ 第 2 条：爬楼不喘了
- 第 3 句 🔴 第 11 条（虚假背书）：专家都说好

改法：`我妈一到阴天就坐楼下，不去跳了。` / `现在她愿意下楼走一圈。` / 删。

**例二（🟡 一处，可发）**
> 我工位抽屉里常年放一瓶，一周点五回外卖，青菜基本见不着啊。吃了八个月，说不上有啥变化。

- 第 1–2 句 🟢 生活事实
- 「说不上有啥变化」🟢 主动降期待
- 结论：可发布。若产品**无蓝帽**，还要删掉任何功能名。

## 自检（静默执行）

- [ ] 蓝帽状态确认过吗？不确定按无蓝帽审
- [ ] 每条判定是否指到具体第几条检查线
- [ ] 有没有把「泛化感受」误判成红线（过度严格会让稿子没法用）
- [ ] 有没有把「无蓝帽 + 功能名」漏掉
- [ ] 改法是否只到单句，没有替用户重写整篇
